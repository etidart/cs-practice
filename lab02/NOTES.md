Рабочая папка - папка, которую контролирует репозиторий
Индекс - промежуточная зона между рабочей папком и самим репозиторием
Коммит - запись в репозитории о состоянии файлов в определённый момент
Git - система контроля версий, а Github - сервис для хранения репозиториев Git и организации совместной работы
git status - отображает текущий статус репозитория
git diff - отображает diff между staged и unstaged версиями
git diff --staged - отображает diff между staged и commited версиями
