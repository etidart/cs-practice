git diff - показывает разницу между двумя указанными коммитами (при их указании) или разницу между текущими staged и unstaged версиями (без указания конкретных коммитов)
git show - показывает разницу между указанным и прошлым коммитом
git log - показывает список коммитов репозитория
git log -S - находит коммиты, в изменениях которых была указанная строка
git blame - для каждой строки файла показывает какой коммит какого человека последним изменил её

git restore - восстанавливает файл, беря за основу последний коммит. git restore --source же позволяет указать, какой коммит брать за основу

git revert отличается от git reset --hard тем, что он создаёт новый коммит с откатом изменений, в отличии от git reset, который просто переносит метку HEAD. В опубликованной истории безопаснее использовать revert, потому что он не переписывает историю.

Отличие тега от ветки заключается в том, что ветка - это подвижный указатель на последовательность коммитов, а тег - это неизменяемая метка на конкретный коммит.
